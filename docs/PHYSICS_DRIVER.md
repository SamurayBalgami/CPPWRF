# WRF Physics Driver & Dycore Coupling Specification

This document specifies the coupling architecture between the CPPWRF dynamical core and the column physics schemes. It documents the exact diagnostic inputs generated by `phy_prep`, the input/output signatures of each scheme (`sfclayrev`, `YSU`, `KF`, `Noah`, and `WSM6`), the destination of each output field, and the execution order within the WRF time integration cycle.

---

## 1. WRF Physics Time-Loop Execution Order

In the Advanced Research WRF (ARW) solver (`dyn_em/solve_em.F` and `dyn_em/module_first_rk_step_part1.F`), physics routines execute in a strict sequential order before the Runge-Kutta acoustic sub-stepping. Physical parameterizations communicate through diagnostic columns and 3D tendency accumulators:

```
+-------------------------------------------------------------------------------+
|                             WRF DYCORE TIME STEP                              |
+-------------------------------------------------------------------------------+
                                       |
                                       v
               +-----------------------------------------------+
               | 1. Radiation Schemes (RRTMG-LW / RRTMG-SW)    |
               |    * Called at radiation frequency (radt)     |
               |    * Outputs: RTHRATEN, SWDOWN, GLW, GSW       |
               +-----------------------------------------------+
                                       |
                                       v
               +-----------------------------------------------+
               | 2. phy_prep (Diagnostic State Reconstruction)  |
               |    * Translates dynamic state (u,v,t,p,ph,al)  |
               |      into physical state (p_phy, pi_phy,      |
               |      t_phy, th_phy, rho, dz8w, p8w, t8w, etc.) |
               +-----------------------------------------------+
                                       |
                                       v
               +-----------------------------------------------+
               | 3. Surface Layer Scheme (sfclayrev)           |
               |    * Surface diagnostics, roughness, drag     |
               |    * Outputs: ust, znt, chs, chs2, cqs2,       |
               |      u10, v10, t2, q2, hfx, qfx               |
               +-----------------------------------------------+
                                       |
                                       v
               +-----------------------------------------------+
               | 4. Land Surface Model (Noah LSM)              |
               |    * Multi-layer soil heat & moisture balance |
               |    * Updates: TSK, HFX, QFX, LH, SSOIL,       |
               |      soil state (STC, SMC, SH2O), snow cover  |
               +-----------------------------------------------+
                                       |
                                       v
               +-----------------------------------------------+
               | 5. Planetary Boundary Layer Scheme (YSU)      |
               |    * Vertical turbulent mixing in column      |
               |    * Outputs: RUBLTEN, RVBLTEN, RTHBLTEN,     |
               |      RQVBLTEN, RQCBLTEN, RQIBLTEN, HPBL       |
               +-----------------------------------------------+
                                       |
                                       v
               +-----------------------------------------------+
               | 6. Cumulus Convection Scheme (Kain-Fritsch)   |
               |    * Deep & shallow subgrid convective plumes |
               |    * Outputs: RTHCUTEN, RQVCUTEN, RQCCUTEN,   |
               |      RQRCUTEN, RQICUTEN, RQSCUTEN, RAINCV     |
               +-----------------------------------------------+
                                       |
                                       v
               +-----------------------------------------------+
               | 7. Microphysics Scheme (WSM6)                 |
               |    * Grid-scale 6-class phase transitions     |
               |    * Directly updates or increments:          |
               |      th, qv, qc, qr, qi, qs, qg, RAINNCV      |
               +-----------------------------------------------+
                                       |
                                       v
               +-----------------------------------------------+
               | 8. Tendency Coupling & Metric Transform       |
               |    * calculate_phy_tend: mu-coupling (mu * ten)|
               |    * update_phy_ten: accumulates to *_tendf   |
               |    * apply_tendf_map_factors: map factor div  |
               +-----------------------------------------------+
                                       |
                                       v
               +-----------------------------------------------+
               | 9. Dycore Runge-Kutta Integration (RK3)       |
               |    * Acoustic substepping with full tendencies |
               +-----------------------------------------------+
```

## 2. Diagnostic State Preparation (`phy_prep`)

`phy_prep` reconstructs the un-staggered physical thermodynamics, heights, and layer thicknesses from dry-core prognostic variables and base state arrays (mirroring `dyn_em/module_big_step_utilities_em.F`).

### Output Fields and Definitions

| Variable | Stagger | Units | WRF Formulation / Definition |
| :--- | :---: | :---: | :--- |
| `th_phy` | Mass | $\text{K}$ | If moist potential temperature used: $\theta = (t_{pert} + T_0)/(1 + \frac{R_v}{R_d} q_v)$; else $\theta = t_{pert} + T_0$. |
| `th_phy_m_t0` | Mass | $\text{K}$ | Perturbation potential temperature relative to reference $T_0$: $\theta - T_0$. |
| `p_phy` | Mass | $\text{Pa}$ | Full pressure: $p = p_{pert} + p_{base}$. |
| `pi_phy` | Mass | - | Exner function: $\pi = (p / P_0)^{R_d / c_p}$ with $P_0 = 10^5\text{ Pa}$. |
| `t_phy` | Mass | $\text{K}$ | Physical absolute temperature: $T = \theta \cdot \pi$. |
| `rho` | Mass | $\text{kg m}^{-3}$ | Moist air density: $\rho = (1 + q_v) / \alpha$. |
| `u_phy` | Mass | $\text{m s}^{-1}$ | Unstaggered cell-center zonal wind: $u_{phy}(i,j,k) = \frac{1}{2}(u(i,j,k) + u(i+1,j,k))$. |
| `v_phy` | Mass | $\text{m s}^{-1}$ | Unstaggered cell-center meridional wind: $v_{phy}(i,j,k) = \frac{1}{2}(v(i,j,k) + v(i,j+1,k))$. |
| `z_at_w` | W | $\text{m}$ | Geopotential height at full levels: $z_{at\_w} = (\phi_{pert} + \phi_{base}) / g$. |
| `dz8w` | W / Mass | $\text{m}$ | Vertical layer thickness: $dz8w(k) = z_{at\_w}(k+1) - z_{at\_w}(k)$ (0 at top boundary). |
| `z` | Mass | $\text{m}$ | Mid-layer height at mass levels: $z(k) = \frac{1}{2}(z_{at\_w}(k) + z_{at\_w}(k+1))$. |
| `p8w` | W | $\text{Pa}$ | Pressure at interface levels via interior weighting ($fnm, fnp$) and logarithmic top/bottom extrapolation. |
| `t8w` | W | $\text{K}$ | Temperature at interface levels via interior weighting and boundary extrapolation. |
| `p_hyd_w` | W | $\text{Pa}$ | Hydrostatic pressure at full levels integrated top-down: $p_{hyd\_w}(k) = p_{hyd\_w}(k+1) - (1 + q_{tot})(c_1 \mu + c_2) \Delta \eta_w(k)$. |
| `p_hyd` | Mass | $\text{Pa}$ | Hydrostatic pressure at half levels: $\frac{1}{2}(p_{hyd\_w}(k) + p_{hyd\_w}(k+1))$. |

## 4. Tendency Coupling and Metric Transformations

Following completion of all physics parameterizations, tendencies are coupled to the dry air mass column $\mu$ and divided by map factors to match the flux-form curvilinear equations solved by the dynamical core.

### 4.1. Mu-Coupling (`calculate_phy_tend`)
Scalar and momentum tendencies from PBL, cumulus, shallow convection, and radiation are multiplied by dry column mass:
- Mass-point tendencies:
  $$\text{ten\_coupled}(i,j,k) = \mu_t(i,j) \times \text{ten\_unphys}(i,j,k)$$
- Zonal momentum (U-staggered):
  $$\text{rublten\_coupled}(i,j,k) = \mu_u(i,j) \times \text{rublten}(i,j,k)$$
- Meridional momentum (V-staggered):
  $$\text{rvblten\_coupled}(i,j,k) = \mu_v(i,j) \times \text{rvblten}(i,j,k)$$

### 4.2. Accumulation into Dycore Tendency Buffers (`update_phy_ten`)
The coupled tendencies are accumulated into the active dycore tendency containers ($ru\_tendf$, $rv\_tendf$, $t\_tendf$, $q\_tendf$):
- $t\_tendf \mathrel{+}= \mu_t \times (RTHRATEN + RTHBLTEN + RTHCUTEN + RTHSHTEN)$
- $q\_tendf[m] \mathrel{+}= \mu_t \times (RQ*BLTEN + RQ*CUTEN + RQ*SHTEN)$
- $ru\_tendf \mathrel{+}= \mu_u \times (RUBLTEN + RUCUTEN + RUSHTEN)$
- $rv\_tendf \mathrel{+}= \mu_v \times (RVBLTEN + RVCUTEN + RVSHTEN)$

### 4.3. Map-Scale Factor Divisions (`apply_tendf_map_factors`)
In conformal map projections (Lambert Conformal, Mercator, Polar Stereographic), the ARW flux-form equations require specific map scale factors in horizontal tendency terms (see WRF Technical Note NCAR/TN-475+STR, Eq. 2.15-2.23):
- **U-momentum tendency:**
  $$ru\_tendf(i,j,k) = \frac{ru\_tendf(i,j,k)}{msfuy(i,j)}$$
- **V-momentum tendency:**
  $$rv\_tendf(i,j,k) = rv\_tendf(i,j,k) \times msfvx\_inv(i,j) = \frac{rv\_tendf(i,j,k)}{msfvx(i,j)}$$
- **Potential temperature tendency:**
  $$t\_tendf(i,j,k) = \frac{t\_tendf(i,j,k)}{msfty(i,j)}$$
- **Scalar moisture tendencies:**
  $$q\_tendf[m](i,j,k) = \frac{q\_tendf[m](i,j,k)}{msfty(i,j)}$$

These operations ensure that all tendencies passed to the acoustic-step Runge-Kutta solver precisely match the continuous WRF discretization.

## 5. Physics Initialization Order for Real-Data Runs ($t = 0$)

Before time-stepping begins, WRF performs static table reading and surface/soil diagnostic initialization (`dyn_em/module_initialize_real.F`, `phys/module_physics_init.F`, and scheme driver inits). CPPWRF mirrors this sequence in `src/phys/driver/physics_init.cpp`:

```
+-------------------------------------------------------------------------------+
|                       CPPWRF REAL DATA INITIALIZATION                         |
+-------------------------------------------------------------------------------+
                                       |
                                       v
               +-----------------------------------------------+
               | 1. Static Parameter Table Reading             |
               |    * LANDUSE.TBL: albedo, z0, emiss, therin   |
               |    * Noah LSM Tables:                         |
               |      - GENPARM.TBL: sbeta, fxexp, czil, etc.  |
               |      - SOILPARM.TBL: bb, maxsmc, satpsi, etc. |
               |      - VEGPARM.TBL: maxalb, z0min/max, etc.   |
               |    * sfclayrev: 1001-element z/L lookup table |
               |    * Kain-Fritsch: kf_lutab (ttab, qstab)     |
               |    * WSM6: Wsm6Params gamma & velocity tables |
               |    * YSU: stateless (no-op in WRF)            |
               |    (Orchestrated by init_physics_tables)      |
               +-----------------------------------------------+
                                       |
                                       v
               +-----------------------------------------------+
               | 2. Grid Surface Characteristics Setup         |
               |    (WRF LANDUSE_INIT / init_surface_properties)|
               |    * Determine season (ISN=1 summer, 2 winter)|
               |      from julday and cen_lat                  |
               |    * Map LU_INDEX to:                         |
               |      ALBEDO, ALBBCK, THC, Z0, ZNT,            |
               |      EMISS, EMBCK, MAVAIL, XLAND              |
               |    * Apply sea-ice overrides (XICE >= 0.02)   |
               +-----------------------------------------------+
                                       |
                                       v
               +-----------------------------------------------+
               | 3. Noah LSM Soil & Surface Initialization     |
               |    (WRF lsminit / init_noah_soil)             |
               |    * SNOALB = MAXALB(IVGTYP) * 0.01           |
               |    * SH2O (liquid soil moisture):             |
               |      - If TSLB >= 273.149 K: SH2O = SMOIS     |
               |      - If TSLB < 273.149 K: iterative solution|
               |        via FRH2O ensuring SH2O <= SMOIS       |
               |    * CANWAT = 0.0, SNOWH = SNOW * 0.005       |
               +-----------------------------------------------+
```

### 5.1. Table Ingestion Details
1. **`LANDUSE.TBL` (`read_landuse_table`):** Ingests seasonal surface properties for datasets such as `MODIFIED_IGBP_MODIS_NOAH` and `USGS`. Provides `albd`, `slmo`, `sfem`, `sfz0`, `therin`, `scfx`, and `sfhc`.
2. **Noah LSM Tables (`noah::read_noah_tables`):** Ingests `GENPARM.TBL` (general soil & runoff parameters), `SOILPARM.TBL` (soil hydraulic properties for 16 soil classes), and `VEGPARM.TBL` (vegetation phenology, root distribution, and seasonal albedo bounds).
3. **`sfclayrev` Stability Functions (`sfclayrev::init_sfclayrev_tables`):** Precomputes 1001-entry lookup tables for universal stability functions $\psi_m(z/L)$ and $\psi_h(z/L)$ in both stable and unstable regimes to avoid expensive transcendentals in runtime column kernels.
4. **Kain-Fritsch Thermodynamic Lookup (`cu_kf::init_kf_tables`):** Precomputes saturated vapor pressure and temperature-pressure thermodynamic tables (`ttab`, `qstab`, `the0k`, `alu`) over the operational range $[100\text{ K}, 350\text{ K}]$ and $[50\text{ hPa}, 1050\text{ hPa}]$.
5. **WSM6 Microphysics Constants (`wsm6::Wsm6Params::init`):** Precomputes gamma distribution lookup parameters, slope-intercept coefficients, and hydrometeor fall velocity scaling constants.
6. **YSU PBL Initialization:** YSU is completely stateless across time steps; its initialization in WRF is a no-op.
